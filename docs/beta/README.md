## Formulario de feedback

El formulario se sirve en `/feedback.html` de la app desplegada (y también
desde **Configuración → Enviar feedback**). Es autocontenido: valida los campos,
construye un reporte estructurado y permite enviarlo / copiarlo sin depender de
servicios externos ni de un backend.
